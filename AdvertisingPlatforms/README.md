## Для запуска и тестирования приложения через Visual Studio 2022/Rider/VS Code потребуется:

1. Установленный .NET 8 SDK;
2. В случае работы с Visual Stduio 2022 потребуются установленные компонент "ASP.NET и разработка веб-приложений";
3. Далее для открытия проекта необходимо через Visual Stuidio/Rider открыть файл с расширение sln. После чего выбрать тип запускаемой конфигурации (IIS/http/https) и запустить приложение.

```
Осторожно с https, если у вас нет настроенного сертификата - приложение не запустится
```

## Для запуска приложение при помощи .exe файла:

Откройте папку, содержащую .exe файл
Для проекта это **path_to_project**\AdvertisingPlatforms\AdvertisingPlatforms\bin\Realese\net8.0\win-x64
Для создания использовалась команда: `dotnet publish -c Release -r win-x64 --self-contained`.

Следовательно, приложение публиковалось под 64 разрядную ОС Windows.

Собранное приложение уже содержит упакованную .NET Runtime.

Для запуска приложения необходимо запустить AdvertisingPlatforms.exe файл.

```
Убедитесь, что порт, на котором запускается приложение ничем не занят
```

По умолчанию приложение запускается по адресу: http://localhost:5000.

Поскольку первый запрос - запрос на выгрузку данных из файла в память является POST запросом, то для обращения к этому endpoint потребуется специальный инструмент.

Я оставил для этого возможность работы со Swagger: http://localhost:5000/swagger.

В качестве альтернативы можно использовать Postman.

Я также попробовал вписать в сборку самописный сертификат.
Можно попробовать запустить по адресу https://localhost:5001/swagger.

После открытия страницы Swagger пользователю будет представлено 2 endpoint.

Первый POST - для загрузки шаблонов из файла (нужно указать путь, поскольку используемый по умолчанию окажется недействительным).

Второй GET - для получения платформы по указанной локации.

Если потребуется, могу запаковать приложение в контейнер Docker.
